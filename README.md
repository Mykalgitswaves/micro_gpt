### What im making

This is a 2 block multi headed attention transfromer loosely based off of GPT-2. It has a vibe coded rust library that is not super performant, 
but i am working on a minified python alternative that is easier to understand. 

Im building this as a fun learning exploration into what makes multi headed attention work and to get a deeper understanding of auto grad engines which power 
libraries like pytorch. Im training this off of anthony bourdain books, which he might actually not be stoked on - so i'm not going to make this a hosted project but
it does make the output interesting to say the least.
